# Theorem Artifact Map

This map links each paper theorem to implemented artifacts. A theorem is
marked supported only when it has a relation/component, backend or verifier,
tests, and benchmark evidence. Table 1 is RL performance evidence and is N/A
for the formal soundness statements below.

Rows are keyed by the LaTeX label, with the current number for convenience.
The label is the stable identifier: inserting a statement renumbers every
theorem after it, and this file has already pointed at the wrong numbers once
because of that. Cite `thm:manifest-aggregation`, not "Theorem 9".

## Non-theorems / Not Claimed

- Not true recursive aggregation over child proofs.
- Full DQN training soundness is not claimed.
- Adam optimizer soundness is not claimed.
- Arbitrary network-size soundness is not claimed.
- Batch-size 4/8/16 training-update proof soundness is not claimed.
- Honest public dataset collection is not claimed for public Minari/D4RL imports.
- All replay batches, model selection, and final policy optimality are not claimed.

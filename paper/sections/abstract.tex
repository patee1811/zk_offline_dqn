Offline reinforcement learning creates a verification problem that is not
captured by supervised proof-of-training alone: a malicious prover can tamper
with replay membership, reward semantics, Bellman targets, terminal flags,
action selection, gradients, checkpoint links, and target-network
synchronization. We present a scoped artifact system for proof-backed
verification of selected Offline-DQN training fragments over provenance-bound
committed replay data. The artifact combines replay/source audits, Merkle
dataset commitments, fixed-point relation witnesses, SP1 proof-backed relation
checks, proof-manifest chunk-chain aggregation, and tamper-rejection reports.

The current implementation supports SP1 proof generation and verification for
the TD MVP canonical vector, Merkle membership including 1k/10k/100k
dataset-size cases, Forward-TD MLP and one-step SGD tiny canonical vectors,
short trace, one-step training update batch size 1, training fragments
$k\in\{1,4,8\}$, and proof-manifest chunk-chain aggregation
$T\in\{32,64,128\}$. Table 1 reports RL performance, Table 2 reports proof
cost, and Table 3 reports tamper rejection with no unexpected accepted tamper
rows. Theorems are mapped to relations, backend code, tests, and benchmark
rows.

The contribution is a claim-safe security/systems artifact, not a general
training proof. It does not claim complete Offline-DQN training soundness,
Adam, batch-size 4/8/16 training-update proofs, proof-backed
$k\in\{16,32,128\}$ fragments, true recursive child-proof verification inside
SP1, or honest collection for public Minari/D4RL imports.

\subsection{Reproduction Commands}
\label{app:reproducibility}

The reviewer fast path from the repository root:
{\scriptsize
\begin{verbatim}
make reproduce-small
\end{verbatim}
}
\noindent This produces a tiny dataset audit report, validates compact proof
provenance, regenerates paper tables, checks theorem/artifact mappings, and
writes the artifact manifest. Additional targets:
{\scriptsize
\begin{verbatim}
make reproduce-data-audit
make reproduce-smoke-sources
make reproduce-sp1-proofs
make reproduce-benchmarks
make reproduce-tamper
make reproduce-paper-tables
make artifact-manifest
\end{verbatim}
}
\noindent Heavy SP1, benchmark, and tamper targets require the SP1 toolchain
and the corresponding \texttt{RUN\_HEAVY\_*} environment flag.

\subsection{Full Python Regression}

The Python regression suite runs 15 checks:
{\scriptsize
\begin{verbatim}
python scripts/experiments/run_full_regression.py
\end{verbatim}
}
\noindent Checks include: compile validation, minibatch TD verification,
forward-TD consistency, one-step update verification, short-trace verification
(contiguous and seeded), negative/tamper tests for one-step, short-trace,
minibatch, and TD~MVP relations, and paper-number consistency checks.

\section{Tamper Test Definitions}
\label{app:tamper-tests}

The tamper benchmark covers the following adversarial modification categories:

\begin{itemize}[leftmargin=1.5em]
  \item \textbf{Data-level}: reward, next state, done flag, action, raw
  trajectory hash, collection log hash.
  \item \textbf{Commitment-level}: Merkle path, Merkle leaf, leaf index,
  dataset root, manifest hash, audit report hash.
  \item \textbf{Computation-level}: Q value, TD target, loss, gradient,
  checkpoint hash.
  \item \textbf{Trace-level}: minibatch index, target network sync, step
  order.
  \item \textbf{Verification-level}: proof public input (roots, hashes,
  relation ID mismatch).
\end{itemize}

For SP1-backed relations, tamper tests include both host-precheck-enabled
mode (where the host JSON parser may catch obvious violations) and
host-precheck-disabled mode (where rejection must come from the guest
relation logic or SP1 verification).

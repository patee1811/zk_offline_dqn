Offline RL trains policies from a fixed replay dataset, so verification must
cover both data provenance and learning arithmetic. A dishonest prover can
change a reward, action, terminal flag, next state, Bellman target, Q value,
gradient, checkpoint link, or target-network synchronization while still
presenting a plausible final checkpoint. The verifier therefore needs evidence
that the checked computation used committed replay data and followed the stated
fixed-point DQN relation.

This paper targets selected Offline-DQN training fragments over
provenance-bound replay data. The system combines audited dataset commitments,
SP1-backed relation proofs, proof-manifest chunk-chain aggregation,
RL/proof/tamper benchmark tables, and a theorem-to-artifact map. The scope is
intentional: each claim is tied to a concrete relation, backend implementation,
test, and benchmark row.

The artifact makes four contributions:
\begin{itemize}[leftmargin=1.5em]
    \item a dataset pipeline that distinguishes self-collected replay/reward
    audits from public benchmark source-integrity imports;
    \item SP1 proof-backed relations for replay membership, Bellman/TD
    arithmetic, tiny MLP forward evidence, one-step SGD, checkpoint chains,
    training fragments, and proof-manifest chunk-chain aggregation;
    \item three generated paper tables: RL performance, ZK proof cost, and
    tamper rejection with explicit rejection layers;
    \item a reviewer artifact package with Make targets, Docker metadata,
    compact hash manifests, and claim-safety checks.
\end{itemize}

The paper does not claim a complete proof that an arbitrary DQN was trained
from initialization to final model. It also does not claim Adam, Atari- or
MuJoCo-scale proofs, batch-size 4/8/16 training-update proofs, proof-backed
$k\in\{16,32,128\}$ fragments, no true recursive aggregation, or honest public
dataset collection.

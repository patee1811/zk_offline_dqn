The implemented proof backend is SP1. Each proof-backed relation follows a
host/guest/shared structure under \path{zk_backend/}: the shared crate defines
typed public inputs, private witnesses, fixed-point arithmetic, hashing, and
relation checks; the guest executes the relation inside the zkVM; and the host
loads JSON fixtures, executes or proves the guest, verifies public values, and
records compact metrics.

The public statement contains roots, hashes, relation identifiers, claimed
outputs, and proof public values. Private witnesses contain opened transitions,
Merkle paths, weights, and intermediate arithmetic values unless a relation
declares them public. Proof binaries and receipts are not committed. Instead,
the artifact commits compact provenance: metrics, public inputs, witness
schemas, verify reports, proof-artifact policy files, and hash inventories.
